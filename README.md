# CONVRGENCE 한국어 패치 v.1.1

배포: **zecole-vr** · **게임 핫픽스 1.0.3 / Windows Steam 빌드 25485319**

게임 업데이트로 해제된 한글 패치를 다시 설치하는 호환 배포판입니다. 새 빌드의 게임 수정 사항을 유지하면서 메뉴·튜토리얼·PDA·임무·상점·대사 번역, 한글 글꼴 및 배치 보정, 영어 대응 음성 연결, 주요 문서·표지·포스터 한글화를 적용합니다. 이전 패치 없이 설치할 수 있습니다.

## 다운로드

[최신 릴리스 다운로드](https://github.com/zecole-vr/CONVRGENCE-KoreanPatch/releases/latest)에서 **CONVRGENCE-KO-v.1.1.zip**을 받으세요. Source code ZIP은 설치 파일이 아닙니다.

**ZIP 암호: `zecole`**

## 설치 방법

1. 게임을 완전히 종료합니다.
2. 7-Zip 또는 반디집 등 AES ZIP 지원 프로그램으로 암호 `zecole`을 입력해 전부 압축 해제합니다.
3. `Install.cmd`를 더블클릭합니다. 게임 폴더를 자동으로 찾으며, 필요한 경우 직접 선택하거나 관리자 권한을 허용합니다.
4. **게임 내 언어 설정에서 반드시 ‘한국어’를 선택합니다.**

지원 원본과 다른 파일은 덮어쓰지 않고 중단합니다. 이 경우 Steam 게임 파일 무결성 검사로 현재 원본을 복구한 뒤 다시 설치하세요.

## 복구 방법

게임을 종료하고 이번 패키지의 `Restore.cmd`를 더블클릭하세요. 게임 폴더의 `.zecole-ko-backup-v1.1-25485319` 백업으로 핫픽스 1.0.3 원본을 복원합니다. 백업이 없으면 Steam 무결성 검사를 사용하세요.

**게임 업데이트 후 이전 v.1.0의 Restore.cmd로 구버전 파일을 복원하지 마세요.**
