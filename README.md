# CONVRGENCE 한국어 패치 v.1.0

배포: **zecole-vr** · Windows Steam 기준 빌드 **25378610**

메뉴·튜토리얼·PDA·임무·상점·대사 번역, 한글 글꼴과 화면 배치 보정, 영어 대응 음성이 확인된 대사의 영어 음성 연결, 주요 문서·표지·포스터 한글화를 포함한 첫 통합 배포판입니다. 이전 시험판 없이 설치할 수 있습니다.

## 다운로드

[릴리스 다운로드](https://github.com/zecole-vr/CONVRGENCE-KoreanPatch/releases/tag/v.1.0)에서 **CONVRGENCE-KO-v.1.0.zip**을 받으세요. Source code ZIP은 설치 파일이 아닙니다.

**ZIP 암호: `zecole`**

## 설치 방법

1. 게임을 종료합니다.
2. ZIP을 암호 `zecole`로 전부 압축 해제합니다.
3. `Install.cmd`를 더블클릭합니다. 게임 폴더를 자동으로 찾으며, 필요한 경우 직접 선택하거나 관리자 권한을 허용합니다.
4. **게임 내 언어 설정에서 반드시 ‘한국어’를 선택합니다.**

## 복구 방법

게임을 종료하고 `Restore.cmd`를 더블클릭하세요. 게임 폴더의 `.zecole-ko-backup-v1` 원본 백업을 사용합니다. 백업이 없으면 Steam의 게임 파일 무결성 검사로 복구하세요.

## 지원 범위 및 참고

- Windows Steam 기준 빌드 **25378610**용입니다.
- 0.x 시험판 사용자는 Steam 무결성 검사 후 설치하세요.
- 세이브·인벤토리·임무 진행도는 변경하지 않습니다.
- PDA 임무 후속 무전, 은신처 방송 및 일부 차량 음성의 추가 자막은 미지원입니다.
- 일부 포스터의 작은 원문이 남아 있으며, 전 구간 플레이 검증은 완료되지 않았습니다.
- 일부 이미지에 생성형 이미지 편집을 사용했습니다.
- 자세한 내용은 압축 안의 `설명서.txt`를 읽어 주세요.

게임 제작사와 관계없는 비공식 패치입니다.
