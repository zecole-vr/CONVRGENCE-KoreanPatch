# CONVRGENCE 비공식 한국어 패치

CONVRGENCE(Steam · PCVR)의 비공식 한국어 패치입니다.

- 메뉴·임무·대사·문서·폰트·이미지를 한글화했습니다.
- **음성 트랙 912개의 한국어 자막**을 함께 설치합니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 최신 버전 | **v1.5.4** |
| 지원 게임 | CONVRGENCE 1.1.2 / Steam 빌드 26946816 / Steam·PCVR 전용 (Quest 단독 실행판 아님) |
| 설치 도구 | [ZECOLE VR 런처](https://github.com/zecole-vr/zecole-launcher) (Windows 10/11 64비트, .NET Framework 4.8, WebView2) |
| 필요 여유 공간 | 백업과 임시 파일용 6 GB 이상 권장 |
| 제작 | 제콜 (ZECOLE) · [YouTube](https://www.youtube.com/@zecole) |

## 설치

**[ZECOLE_Launcher.exe 받기](https://github.com/zecole-vr/zecole-launcher/releases/latest/download/ZECOLE_Launcher.exe)** · 설치 없이 바로 실행 · 설치·업데이트·원본 복구를 모두 런처에서 합니다.

1. Steam에서 게임이 **1.1.2**로 업데이트되었는지 확인하고, 게임을 완전히 종료합니다.
2. 런처를 실행하고 왼쪽 목록에서 **CONVRGENCE**를 고릅니다.
3. **한글패치 설치** 버튼을 누릅니다. Windows 권한 요청이 나타나면 **예**를 눌러 주세요. (게임 경로는 자동으로 찾습니다.)
4. 완료 후 게임을 실행하고 **인게임 언어를 반드시 ‘한국어’로 선택**합니다.

### 알아 둘 점

- 최초 신규 설치에는 인터넷이 필요합니다. 약 1.3 MB의 보조 라이브러리를 자동으로 내려받아 검증합니다.
- 자막 플러그인·로더·자막용 .NET 런타임은 한글패치 데이터에 포함되어 별도 설치할 필요가 없습니다.
- 게임 업데이트 후 첫 실행은 자막용 연결 파일을 다시 만드느라 평소보다 오래 걸릴 수 있습니다.
- 설치 중에는 게임 실행·Steam 업데이트·PC 종료를 피해 주세요.
- v1.5.0~v1.5.3에서 쓰던 검증된 자막 실행 환경의 소유 기록은 이어서 사용합니다.
- 지원하지 않는 버전이나 알 수 없는 파일은 변경하지 않습니다.
- 새 한글패치 버전이 나오면 런처가 **업데이트 있음**으로 알려 주며, 같은 화면에서 설치하면 됩니다.

## v1.5.4 패치 내용 — 게임 1.1.2 대응판

### 바뀐 점

- 게임 **1.1.2 (Steam 빌드 26946816)** 업데이트에 대응했습니다. 기존 메뉴·임무·대사·문서·폰트·이미지 한글화와 추가 음성 자막을 새 빌드로 옮겼습니다.
- 이번 게임 업데이트에서 바뀐 글은 화면의 버전 표시(v 1.1.2)뿐이라 번역 내용은 v1.5.3과 같습니다.
- v1.5.3 사용자는 Steam에서 게임을 1.1.2로 업데이트한 뒤 런처에서 **한글패치 설치**를 누르면 됩니다.
- 이전 게임 빌드의 원본 백업은 따로 보존하고, 새 빌드 원본을 다시 백업합니다.
- 이번 버전부터 설치기 EXE 없이 ZECOLE VR 런처로만 설치합니다.

### 음성 자막 912개

| 구분 | 개수 |
|---|---|
| PDA·차량 무전 | 68 |
| 은신처 관제방송 | 78 |
| 맵 관제무전 | 43 |
| 모닥불 NPC | 3 |
| 적 전투 음성 | 720 |

- 관제무전은 문장 전체를 줄바꿈하여 표시합니다.
- 적 자막은 거리 제한 없이 최대 2개를 표시하며, 수류탄 경고를 우선합니다.
- 음성 자체의 거리 감쇠는 변경하지 않습니다.

### 확인 범위와 제한

- 실제 게임 1.1.2에서 런처로 설치한 뒤 자막 플러그인 로드(자막 912개)와 게임 화면 표시를 확인했습니다.
- 일부 포스터의 작은 본문 등에는 원문이 남아 있습니다.
- 전체 게임 구간과 모든 음성 자막을 이번 버전에서 다시 시험한 것은 아닙니다.
- 게임 업데이트로 파일이 바뀌면 새 대응 패치를 기다려 주세요.

## 복구법

1. 게임을 완전히 종료합니다.
2. 런처의 CONVRGENCE 화면에서 **원본 복구**를 누릅니다. Windows 권한 요청이 나타나면 **예**를 눌러 주세요.
3. 완료 후 게임을 실행합니다.

### 복구되는 범위

- 관리하는 한글패치와 추가 자막 파일을 제거하고, 백업한 원본을 복구합니다.
- 세이브와 다른 모드는 일괄 삭제하지 않습니다.
- 기존 공용 로더는 복원·보존하며, 다른 모드가 사용하는 로더도 보존합니다.

### 백업과 기록

- 백업·설치 기록·로그: `%LOCALAPPDATA%\ZECOLE\CONVRGENCE` — **복구 전 이 폴더를 삭제하지 마세요.**
- 예전 설치기 EXE로 설치했어도 런처가 같은 기록을 이어서 사용합니다.
- 백업이 없거나 손상된 경우에는 Steam의 게임 파일 무결성 검사로 원본을 복구할 수 있습니다.
